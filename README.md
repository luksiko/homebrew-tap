# homebrew-tap

Official Homebrew tap for [Dopishi](https://github.com/luksiko/dopishi) — smart keyboard layout switcher, inline auto-correction and text converter for macOS.

## Installation

```bash
brew install --cask luksiko/tap/dopishi
```

Or tap first:

```bash
brew tap luksiko/tap
brew install --cask dopishi
```

## Updates

```bash
brew upgrade --cask dopishi
```
